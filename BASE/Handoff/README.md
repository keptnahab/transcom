# Handoff Index

Files:
- `HANDOFF.md`: fast resume snapshot
- `00_PROJECT_STATUS.md`: current goal, progress, milestone
- `01_CONTEXT.md`: product context, constraints, user expectations
- `02_TODO.md`: prioritized actionable worklist
- `03_ARCHITECTURE.md`: code structure and runtime architecture
- `04_DECISIONS.md`: important decisions and why they were made
- `05_PROGRESS_LOG.md`: chronological implementation history
- `06_SESSION_SUMMARY.md`: latest verified session summary
- `07_KNOWN_ISSUES.md`: unresolved bugs, risks, and regressions
- `08_SETUP.md`: local setup, run, build, and operational notes

Reading order for a fresh context:
1. `HANDOFF.md`
2. `00_PROJECT_STATUS.md`
3. `02_TODO.md`
4. `06_SESSION_SUMMARY.md`
5. `07_KNOWN_ISSUES.md`
6. `03_ARCHITECTURE.md`
